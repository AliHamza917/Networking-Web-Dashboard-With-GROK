End-user usage manual

Ali Hamza Cisco Networking Dashboard helps you manage Cisco IOS / IOS-XE switches from a browser.

1. Connect

  • SSH: enter switch IP, username, password (enable secret if needed), port 22 → Test Connection.
  • Console cable: choose Console, select COM port (Detect), baud 9600, same user/pass → Test Connection. Close Putty on that COM first.

2. Port Map

Refresh Ports. Green = access up, blue = trunk, gray = down. Click a port to see MAC and IP of connected hosts.

3. Topology / Track Route

Topology uses CDP/LLDP. Track Route runs traceroute from the switch and shows a visual hop map.

4. Monitor & IP Scanner

Monitor continuously pings saved switch IPs and alerts if one goes down. Scanner finds live hosts; device type is a guess (PC / mobile / network) based on TTL — not 100% accurate, and a switch may look like a PC if TTL is rewritten.

5. Config / Backup / Restore

  • Config Push: paste CLI lines and apply.
  • Backup: download running-config.
  • Upload & Apply Backup: restore from a .cfg file (review carefully before production).

6. Safety

Lab / trusted networks only. Always review commands. © Ali Hamza · alihamza51326@gmail.com
